# SubLog プライバシーポリシー

最終更新日：2026年11月14日

SubLog（以下「本アプリ」）は、サブスクリプションの管理に必要なデータを、利用者の端末と、利用者自身の iCloud の中で扱います。開発者は、利用者の行動を集めるサーバー、広告、アクセス解析、クラッシュ解析の仕組みを使っていません。

## 1. 本アプリで扱うデータ

利用者が入力した、サービス名、金額、通貨、請求の周期、次の請求日、カテゴリ、メモ、URL、支払い方法、無料トライアル、価格の変化、解約の方法などのサブスクリプションの情報と、通知の履歴、本アプリの設定を扱います。

これらは本アプリの機能のためだけに使い、開発者へ送りません。本アプリには、氏名、メールアドレス、電話番号、位置情報、連絡先、端末の識別子を集める機能はありません。

## 2. 保存する場所

データは利用者の端末の中に保存します。

SubLog Pro で iCloud 同期を有効にした場合は、Apple の CloudKit の、利用者自身のプライベートな領域を使って同期します。

SubLog Pro のバックアップを使った場合は、バックアップのファイルを利用者の iCloud Drive（使えない場合は端末の中）に保存します。

開発者が、利用者の iCloud や iCloud Drive の中身を見る仕組みはありません。Apple による処理には、Apple のプライバシーポリシーが適用されます。

## 3. 開発者に届く情報

本アプリから開発者に情報が届くのは、利用者が自分で送る次の 2 つの場合だけです。

アプリ内のフィードバック：利用者が書いた本文と種類（不具合、要望、その他）、本アプリの版とビルド番号、iOS の版、端末の機種、言語の設定を送ります。氏名、連絡先、登録したサブスクリプションの情報は含みません。送られた内容は、Cloudflare のサーバーを通して、開発者の非公開の GitHub のリポジトリに保存し、本アプリの改善のためだけに使い、不要になったものは削除します。送り過ぎを防ぐため、送信元の IP アドレスを回数の確認のためだけに一時的に使い、保存しません。フィードバックには返信できません。

メールでのお問い合わせ：利用者がメールのアプリから support@yutodev.com へ送った内容を、返信のためだけに使います。本アプリが作るメールの下書きには、本アプリの版、iOS の版、端末の機種が入り、送る前に利用者が確かめて消すことができます。

## 4. 外部との通信

為替レート：複数の通貨を換算するため、公開されている為替レートを FloatRates（www.floatrates.com）から 1 日に 1 回まで取得します。この通信に利用者のデータは含めません。接続先では、通信に伴う IP アドレスなどが処理される場合があります。

このほかに本アプリが外部と通信するのは、上のフィードバックと、Apple の iCloud 同期、App Store での購入と復元だけです。

## 5. 端末の中だけで使う機能

スクショから追加：利用者が選んだ写真や、カメラで写した画面から、端末の中の文字の読み取りの機能（Apple の Vision）でサービス名と金額を読み取ります。画像は保存も送信もしません。写真は、利用者が選んだものだけを読み込みます。

カレンダー連携（SubLog Pro）：利用者がカレンダー連携を有効にした場合、iOS のカレンダーへのアクセスを求めます。本アプリは「SubLog」という名前のカレンダーを探すか作り、請求日を終日の予定として追加し、登録と合わなくなった予定をそのカレンダーから削除します。「SubLog」のカレンダーには、本アプリと関係のない予定を入れないでください。予定は開発者へ送りません。

アプリロック：Face ID、Touch ID、パスコードによる確認は、iOS が端末の中で行います。生体の情報が本アプリや開発者に渡ることはありません。

通知：請求日、無料トライアルの終わり、契約の記念日、月のまとめのお知らせは、端末の中のローカル通知で行います。

ウィジェット、Siri、Spotlight：ウィジェットに今月の合計と次の支払いを、Siri に今月の合計を出します。Spotlight で検索できるように、サービス名、金額、カテゴリ、支払い方法を端末の中の検索の索引に登録します。索引は端末の中にだけあり、本アプリを削除すると消えます。

## 6. 購入

SubLog Pro の購入と復元は、Apple の App Store を通して行います。開発者は、カード番号などの支払いの情報を受け取りません。

## 7. 第三者への提供とトラッキング

開発者は、利用者のデータを売りません。法令に基づく場合を除き、第三者に提供しません。本アプリは、他社のアプリやウェブサイトをまたいで利用者を追跡するトラッキングを行いません。

## 8. 子どものプライバシー

本アプリは、子どもを含むどの利用者からも、個人を特定する情報を集めません。

## 9. データの削除

本アプリの設定の「データをリセット」で、登録したサブスクリプションをすべて削除できます。iCloud 同期を有効にしている場合は、同期した先からも削除されます。設定、通知の履歴、為替レートの一時的な保存、カレンダーに追加した予定、iCloud Drive のバックアップのファイルは、この操作では消えません。

カレンダーの予定はカレンダーのアプリから削除できます。バックアップのファイルと、iCloud に保存した本アプリのデータは、iOS の設定の iCloud のストレージの管理から削除できます。本アプリを削除すると、端末の中の本アプリのデータは削除されます。

送ったフィードバックの削除を希望する場合は、送った日時と内容を添えて support@yutodev.com へご連絡ください。

## 10. このポリシーの変更

機能やデータの扱いが変わるときに、このポリシーを更新し、このページでお知らせします。

## 11. お問い合わせ

このポリシーについてのご質問は、support@yutodev.com へお送りください。
