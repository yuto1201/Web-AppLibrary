# 継続的な受け入れ条件

ID と検証ファイルの対応は [config/acceptance.json](../config/acceptance.json) を正本とする。`npm run audit:trace` は対応の存在を検証し、テストの実行成功は `check` / `verify` で別途確認する。

- AC-1: registry の妥当性・画像と静的ルートの実在を維持する。
- AC-2: Node/npm、静的サイトの方針、文書リンク、生成されたエージェント設定のずれを失敗として検出する。
- AC-3: desktop/mobile で一覧行からの遷移、ステッカーのドラッグとクランプ、設定の再読み込み、実配色のコントラスト、詳細・プライバシーの往復を検証する。
- AC-4: 必須チェックとして記録した名前が実際の CI ジョブと Ruleset export に存在し、GitHub Actions App に固定されている。レビュー証拠の確認は所有者が行い、テストの成功を承認と見なさない。
- AC-5: ローカル配信は `out/` に限定し、未知のページは 404、外部ファイルへのパス逸脱は拒否する。

ビルドやテストの成功は、法務本文の確認、公開先の稼働、DNS の状態、レビュー担当者の身元を証明しない。
