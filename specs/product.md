# プロダクト仕様

AppLibrary は個人開発したアプリの紹介サイト。訪問者が一覧から各アプリの特徴、スクリーンショット、配布先、プライバシーポリシーを確認できる。

- 掲載対象は iOS / iPadOS / macOS / watchOS / visionOS / Web / CLI。
- アプリ情報は `src/data/registry.ts`、本文は `src/data/privacy/`、画像は `public/apps/` に保持する。
- 表示設定はテーマと言語のみ。端末の localStorage に保存し、アカウントを作らない。
- Next.js App Router の静的出力を Cloudflare Pages からドメインルートへ配信する。
- トップページは Issue #65 で指定された Slush の参照デザインをもとに、空色の遊び場、大きな黒い装飾ワードマーク、オリジナルの青い立体ループ、パステルの丸い作品カードへ刷新する。実際の見出しと紹介は遊び場の下に置く。実画面を選んで見られる展示、制作の背景・更新ノート・連絡先を持つ。掲載情報と実画面は registry を参照する。
- ホームは light / dark の保存テーマに対応し、空色に黒い文字のキャンバスと、夜色に明るい文字のキャンバスを切り替える。装飾ワードマークは SVG の図形とし、実際のブランド名と見出しは読み上げられるテキストで残す。ピル状の操作を基本に、展示はラベンダー、制作の背景はミント、連絡先は黄色で区切り、これらの明るい面は黒い文字を維持する。既存の詳細・法務ページへホームの意匠を波及させない。掲載数が一覧の絞り込みを必要としないため、検索とフィルタは持たない。掲載アプリが 10 件を超えたら再検討する。
- 遊びは掴んで動かせるビニールステッカー。4枚のアプリと3枚の装飾は、全幅で Hero の専用領域に初期配置する。領域の下端72pxに遊び方とリセットを置き、本文・CTA・展示の操作を覆わない。ドラッグはページ全体にでき、リセットで遊び場へ戻る。テーマと言語の保存、キーボード操作、reduced motion を維持する。
- 個別ページは原則としてアイコンの色味に寄せた紙と標本ビニール 1 枚。CafLog は Issue #69 のユーザー依頼により、実アイコンとアプリ画面を反映した明るい地色・濃い文字・オレンジとピンクの装飾の専用ページを持つ。Hero は実アイコンと実際のホーム画面を紹介し、ギャラリーは登録された全5画面を保持する。SubLog は Issue #67 のユーザー指定の Ventriloc 参照デザインをもとに、青を主色、黄緑を差し色とし、実アイコンの丸い立方体の形を反映した専用ページを持つ。CafLog と SubLog の配色は保存テーマにかかわらず一定で、標本ビニールは置かない。法務ページは共通の紙面と保存テーマを維持する。机の散らしはホームだけ。スクショは実画像のページ内ギャラリーで、モーダルは持たない。
- SubLog は6件の登録済み機能と4枚の実画面、App Store とプライバシーポリシーへのリンクを維持する。ページ内の支払い表示例は月額3,670円と年額44,040円を切り替えられ、「表示例」の明示と `aria-pressed`、キーボード操作を備える。表示例に実データや節約効果の意味を持たせない。詳細な意匠は [個別ページのデザイン仕様](../docs/design/app-page.md)、ホームとの境界は [トップページのデザイン仕様](../docs/design/top.md) に記録する。
- 公開 URL と掲載内容は意匠の変更で変えない。

DB、認証、API サーバー、Supabase、Cursor Cloud の起動、テンプレート生成、プロバイダー操作の自動化は本移植の対象外。将来必要になった時は別 Issue として設計する。

サイト共通の利用規約は `/terms/`、ウェブサイトのプライバシーポリシーは `/privacy/` で静的公開する。アプリ別のプライバシー本文はテンプレートの未確認文言を公開せず、現行実装・既存公開文書・公開 App Store のプライバシー表示と照合する。
