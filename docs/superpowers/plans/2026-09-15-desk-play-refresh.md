# Desk-play refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep the cream poster, but start with stickers already on the paper, add per-app vinyl shapes and pencil notes, desk marks, a specimen vinyl on app pages, and a matching OGP.

**Architecture:** A `DESK_ITEMS` catalog drives home slots (hero / apps / pile). `VinylSticker` is the shared pointer-drag unit; home and app-page specimen pass different `boundsFrom`. Desk tape/stamp/hint are non-interactive CSS. OGP is regenerated by `tools/generate-ogp.py`.

**Tech Stack:** Next.js static export, CSS tokens, React pointer events, existing `src/lib/drag.ts`, Vitest, Playwright, Pillow OGP.

## Global Constraints

- `--paper` light `#fff8f1`; `--ink` light `#000000`; `--accent` light `#0066ee` / dark `#6eb3ff`
- Display Latin: Newsreader 400. UI: Inter 300/400. Hand only: Klee One 400 as `--font-hand`. No Bricolage. No weight 600+ on home UI
- CTA stays outlined pill. Hero copy stays 「小さなアプリを、丁寧に。」
- Stickers: existing `icon.png` vinyl; no app names on stickers; clamp to paper (home) or `.app-shell` (specimen); not `position: fixed`
- `page.tsx` stays a Server Component
- No search/filter/modal, no drag library, no new illustrations, no paper noise/stains
- Drag contract unchanged: paper coordinates, tap vs drag, lever spin, hover/focus not mixed, resize aborts, `touch-action: pan-y`
- `npm run verify` must pass; axe `color-contrast` on real colors
- Touching `tools/generate-ogp.py` makes the PR high-risk: OpenAI and Anthropic independent read-only reviews
- 1 Issue / 1 branch / 1 PR (this branch). Create the GitHub Issue if the token allows; if 403, leave the number blank and record that in the PR
- Do not merge to `main` without explicit user approval of that exact target

```ts
import { apps, type App } from "@/data/registry";

export type StickerShape = "round-rect" | "circle" | "squircle" | "round-lg";
export type DeskAnchor = "hero" | "apps" | "pile";

export type DeskAppItem = {
  key: string;
  kind: "app";
  slug: string;
  shape: StickerShape;
  anchor: DeskAnchor;
};

export type DeskWordItem = {
  key: string;
  kind: "word";
  word: string;
  anchor: DeskAnchor;
};

export type DeskItem = DeskAppItem | DeskWordItem;

const APP_DESK: Record<string, Pick<DeskAppItem, "shape" | "anchor">> = {
  sublog: { shape: "round-rect", anchor: "hero" },
  caflog: { shape: "circle", anchor: "hero" },
  "dev-tools": { shape: "squircle", anchor: "apps" },
  "pay-cycle": { shape: "round-lg", anchor: "pile" },
};

const WORDS: DeskWordItem[] = [
  { key: "note-Swift", kind: "word", word: "Swift", anchor: "pile" },
  { key: "note-Tokyo", kind: "word", word: "Tokyo", anchor: "hero" },
  { key: "note-solo", kind: "word", word: "一人制作", anchor: "pile" },
];

export const DESK_ITEMS: readonly DeskItem[] = [
  ...apps.map((app) => {
    const desk = APP_DESK[app.slug];
    if (!desk) throw new Error(`机の配置が無い slug: ${app.slug}`);
    return { key: app.slug, kind: "app" as const, slug: app.slug, ...desk };
  }),
  ...WORDS,
];

export function deskApp(slug: string): DeskAppItem {
  const item = DESK_ITEMS.find((entry): entry is DeskAppItem => entry.kind === "app" && entry.slug === slug);
  if (!item) throw new Error(`机に無い slug: ${slug}`);
  return item;
}

export function statusStamp(status: App["status"]): "α" | "β" | null {
  if (status === "alpha") return "α";
  if (status === "beta") return "β";
  return null;
}
```

If `App` is a type-only export issue, import `type { App }` from `@/data/schema` instead of registry.
