# 個別ページをポスター紙面へ揃える

ステータス: 採択
最終更新日: 2026-09-15

参照: [ポスターの上に机の跡を残す](2026-09-15-desk-play-refresh-design.md)（ホームの契約）、[アプリ詳細ページのデザイン](../../design/app-page.md)（現行の個別ページ）

## 背景

ホームはクリーム紙と電圧ブルーのポスターになり、その上に机の跡がある。個別ページ (`/apps/<slug>/`) とアプリ法務 (`/apps/<slug>/privacy/` `/terms/`) は、机の刷新でも対象外のまま、紫とピンクの放射グラデ・中央寄せのスプラッシュ・字重 800・塗りつぶし CTA のスタジオ型が残っている。標本ビニールだけが新しい紙面から迷い込んでいる。

E2E もそれを前提にしている。`FLATTEN_APP_SHELL` は「個別ページは再設計の対象外で radial-gradient を使う」と書いてあり、dark でも `.section-title` を `rgb(22, 24, 29)` に固定している。サイトのテーマを切っても個別ページだけ明るいスタジオのまま、という切れ目がある。

机の仕様が先送りした「詳細ページ全体をポスター型に組み直す」を、この仕様が引き受ける。

## 決定

見立ては **同じポスターの続きのページ**。ホームで見た紙を裏返したのではなく、同じ束の次の一枚。遊びは標本ビニール 1 枚だけ。机の散らし・テープ・日付印・手書き合図はホームに残す。

実装は 1 Issue / 1 PR。Issue は未起票（この環境の GitHub Issue 作成が 403 のため番号は空欄）。`#36` の机の跡の上に載せる。`#36` が未マージならこの変更は机の Head から分岐する。

### 1. 紙とインク

`.app-shell` と `body:has(.app-shell)` はサイトの `--paper` / `--ink` を使う。`#f8fafc`、`#eef2ff`、`#fdf2f8`、放射グラデ、`color-scheme: light` の固定は捨てる。

`--app-*` の**名前は残す**（既存の隔離契約）。値だけ紙面へ寄せる。

| トークン | 値 |
|---|---|
| `--app-bg-base` / `--app-bg-1` / `--app-bg-2` | `var(--paper)` |
| `--app-ink` | `var(--ink)` |
| `--app-ink-2` | `var(--ink-2)` |
| `--app-accent` / `--app-accent-2` | `var(--accent)` |

`[data-theme="dark"]` は `tokens.css` の差し替えに従う。個別ページだけ light に閉じない。

サイト共通の `/privacy/` `/terms/` はすでに紙面トークンなので、この仕様の対象外。

### 2. 組版

セクション順は変えない。戻る → アイコン / 名前 / 紹介 / プラットフォーム / CTA → Features → Screenshots → フッター。

- 本文・UI: Inter 300 / 400。個別ページの UI に 600 以上を使わない。
- 英語見出し（Features / Screenshots）: Newsreader 400（`--font-display`）。
- 日本語のアプリ名: OS ゴシックへ落とす。字重は 400。電圧ブルーにはしない（本文はインク、色は操作に限る）。
- タグライン: `--ink-2`。グラデ文字は捨てる。
- 行長はホームと同じ `--measure`（760px）。Hero は中央寄せのスプラッシュをやめ、左揃えの一段組にする。
- 戻るリンクは残す。ホームの `<Nav />` は載せない（`#apps` などページ内アンカーが個別ページに無い）。テーマ切替はホームで行い、保存値は個別ページでも効く。

### 3. 操作

CTA はホームと同じ outlined pill。塗りグラデ、浮き上がり、白いゴースト面は捨てる。

- 配布先（App Store / Web）: 電圧ブルーの枠と文字。
- 「機能を見る」: 同じ pill 形で、枠と文字はインク。塗り面にしない。
- バッジ（プラットフォーム）: 1px 罫線。白の半透明面は捨てる。

### 4. Features と Screenshots

Features は印刷された項目。白いカード、ぼかし影、字重 700 は捨てる。今のグリッドは残し、各項目は塗りなし・1px 罫線だけにする。

Screenshots は机に置いた写真。1px 罫線と `--shadow-sticker` は残す。紫の大きなドロップシャドウと、黒ベタの背景は捨てる。角丸は現行の 28px のまま。背景は `--paper`。

### 5. 標本ビニール

現行の契約を維持する。Hero 右上にそのアプリのビニール 1 枚。リンクではない。`aria-hidden`。クランプは `.app-shell`。法務ページには置かない。追加の散らし・テープ・印・手書きは置かない。

Hero の大きなアイコンは 120px のまま残す。紫のグローは外す。標本と役割が被るので、アイコンは印刷、標本は置いてある物、と分ける。

### 6. アプリ法務

`/apps/<slug>/privacy/` と `/apps/<slug>/terms/` も `.app-shell` の紙面トークンに乗る。見出しと本文はインク。標本は置かない。サイト法務ページの文言・構造は触らない。

## 持たないもの

ホームの机の散らし、マスキングテープ、`TOKYO '26`、手書き合図、ホーム `<Nav />`、`ActivateProvider`、検索・フィルタ・モーダル、Liquid Glass、新規イラスト、紙のノイズ / 染み、一覧のカード化、Hero の追加自動演出、スクロール連動、シール位置の永続化、OGP の再生成、`tools/`、DNS / Vercel / Cloudflare、サイト共通 `/privacy/` `/terms/` の組み直し。

## 検討した代替案

- **色だけクリームにする。** 中央寄せ・字重 800・塗り CTA が残る。紙面ではなく塗り替えたスタジオのまま。不採用。
- **紙面トークンと組版を揃える（採用）。** セクションと標本は残し、紙・字・操作だけをホームへ寄せる。個別ページを机の第二面にはしない。
- **ホームと同じ散らしを個別ページにも置く。** 遊びは増えるが、詳細を読むページで本文が隠れる。机の仕様が先送りした理由のまま。不採用。

## 影響

- 変更: `src/styles/app-page.css`（紙面化）、必要なら `src/app/apps/[slug]/page.tsx` のクラス（中央寄せ解除、CTA）、アプリ法務ページはトークン追随、`tests/e2e/site.spec.ts`（`FLATTEN_APP_SHELL` 削除、dark 見出しをインク色へ）、`docs/design/app-page.md`、`docs/verification.md`（個別ページも実配色）、`specs/product.md`（遊びはホーム、個別は同じ紙）、`docs/TODO.md`。
- 触らない: `tools/`、`public/ogp.png`、`src/styles/tokens.css` のトークン名、ホームの机カタログ、`src/styles/legal.css`。
- `docs/verification.md` と `specs/product.md` に触れるため高リスク。独立した OpenAI / Anthropic 両系統の読み取り専用レビューを取る。
- テスト: 個別ページの `body` / `.app-shell` が `PAPER` と同じ。dark の見出しはクリームインクで、`rgb(22, 24, 29)` 固定を捨てる。axe は平坦化なし。標本は詳細に 1 枚、法務に 0 枚。640px で横スクロールなし。ホームへ戻ると紙面の配色のまま（切れ目が消える）。

## 受け入れ条件

- [ ] `/apps/<slug>/` のキャンバスがクリーム紙（dark は濃いインク紙）。紫ピンクのグラデが無い
- [ ] アプリ名はインク、タグラインにグラデ文字が無い。英語見出しは Newsreader
- [ ] CTA が outlined pill。塗りグラデの primary が無い
- [ ] Features に白いカード影が無い。Screenshots は罫線＋シール影
- [ ] 標本ビニールは詳細に 1 枚、法務に無い。追加の机オブジェクトが無い
- [ ] 保存した dark で個別ページの見出しがインク色になる。電圧ブルーに飲まれない
- [ ] axe `color-contrast` を実際の配色で通す（`FLATTEN_APP_SHELL` なし）
- [ ] `npm run verify` が通る。高リスクのため OpenAI / Anthropic 両系統の独立レビューを取る

## 検証

`npm run verify`、ローカル静的配信での light / dark / 日本語 / 英語、desktop と 640px。トップから詳細、詳細から privacy / terms、戻ってトップ。ライブ本番はマージ後の別証拠。
