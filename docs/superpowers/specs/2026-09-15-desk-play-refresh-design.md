# ポスターの上に机の跡を残す

ステータス: 採択
最終更新日: 2026-09-15

参照: [ポスター紙面とフッターのシール山](2026-09-14-poster-sticker-footer-design.md)（完了・紙面の契約）、[もう少し面白さを足す](../../decisions/2026-09-09-more-fun-paper-stickers.md)

## 背景

#30 / #31 でトップはクリーム紙と電圧ブルーのポスターになり、シールはフッター下端の山に閉じた。組版は悪くない。一方で最初の画面から遊びが見えず、シールはアイコンの白フチで個性が薄く、紙面がスタジオのカタログに寄っている。

所有者の要望:

- 最初の画面からシールが紙に乗っている
- つまむ遊びにアプリらしい個性と反応がある
- 個人の机・手帳の気配を紙面にも出す
- 今の雰囲気（クリーム、電圧ブルー、索引の一覧、触れるのはシール）は保つ
- やり方は任せる。結構新しめに刷新し、一旦遊びのあるサイトにする

## 決定

見立ては **組版されたポスターを、作業中の机に置いたままにした**。印刷はきれい、その上にビニールとテープと鉛筆が乗っている。

#31 の「初期配置はフッターの山」は、この仕様が上書きする。ドラッグの物理（紙座標、viewport 固定なし、横スクロールなし、タップで遷移、てこの傾き、相互ハイライト、リサイズで中断）は維持する。

実装は 1 Issue / 1 PR。公開の完成形はホームの机・個別ページの標本・OGP まで揃った状態とする。Issue は未起票（この環境の GitHub Issue 作成が 403 のため番号は空欄）。

### 1. 最初の画面に散らす

初期配置は固定の「机の跡」で、読み込みごとに乱さない（E2E とカタログの探しやすさのため）。

desktop（641px 以上）:

| シール | 初期位置 |
|---|---|
| SubLog | Hero 見出しの右マージン。文字の読みを消さない |
| CafLog | Hero 本文〜 CTA の左下。CTA のヒット領域は覆わない |
| Dev-Tools | App Library の見出し罫線上。文鎮。最初の索引行は覆わない |
| PayCycle | 右下の小さな山（紙の下へはみ出してよい） |
| Swift | 右下の山 |
| Tokyo | Hero の拠点メモ付近 |
| 一人制作 | 右下の山 |

640px 以下:

- アプリシール 1 枚だけ Hero 右端から覗く（見出しグリフと CTA を覆わない）
- 1 枚は App Library 見出しの脇
- 残りは画面下の小さな山
- 横スクロールは出さない

`.sticker-stage` は `.poster` 全面の位置決め用（背景なし、`pointer-events: none`）。ヒットは各シールだけが受ける。透明の塗りレイヤーで本文を覆って axe のコントラストを壊さない。Nav の z-index は初期配置のシールより上。ドラッグ中のシールは本文の上へ出てよい。

「ならべ直す」はフッター付近に残し、**この机の配置**へ戻す。リサイズは現行どおりオフセットを捨て、進行中ドラッグを中断する。

### 2. シールの個性

新規イラストは描かない。既存 `icon.png` のビニールを、アプリごとに形を変える。

| slug | 形 | サイズ感 |
|---|---|---|
| sublog | 角丸四角（現行に近い） | 基準 |
| caflog | 円 | やや小さめ |
| dev-tools | 角の効いた squircle | 基準 |
| pay-cycle | やや大きい角丸 | やや大きめ |

alpha / beta だけ、ビニール右下に小さな `α` / `β` のスタンプを乗せる（シールと一緒に動く。別ヒット対象にしない）。release は印なし。一覧の StatusMark と同じ意味。

飾りビニール（`aria-hidden`、遷移しない）:

- Swift
- Tokyo
- 一人制作（言語を切り替えない。お土産の切り抜き）

アプリ名はシールに書かない。名前は一覧が持つ。

### 3. 掴んだときの反応

現行のてこの傾き・破線の跡・持ち上げ影は残す。足すのは次の 2 つ。

1. **剥がれ。** 掴んでいる間だけ少し大きくする（おおよそ `scale(1.06)`）。`prefers-reduced-motion` では拡大しない。傾きとドラッグ自体は残す。
2. **鉛筆メモ。** アプリシールをホバー / フォーカス / 掴んでいる間、近くに短い手書きを出す。`pointer-events: none`。離すと消える。飾りシールには出さない。

メモは registry の `stickerNote`（日本語、1〜24 字、必須）。アプリ説明と同じく言語切替しない。表示は `lang="ja"`。英語 UI でも日本語のまま（一覧の tagline と同じ）。

初期値:

| slug | stickerNote |
|---|---|
| sublog | 月の固定費、見えてる？ |
| caflog | 今日、何杯目？ |
| dev-tools | ブラウザで足りる |
| pay-cycle | 次の給料日まで |

### 4. 机の気配（ドラッグしない）

紙に粒子・染み・コーヒー輪は足さない。オブジェクトは幾何と文字だけ。

- **マスキングテープ。** CSS の短い帯。App Library 見出しの下に少し回転して覗く。見出し文字のコントラストを落とさない（文字の背面、または文字から外した位置）。
- **日付スタンプ。** JetBrains Mono の枠文字 `TOKYO '26`。Hero 右上付近。`aria-hidden`。Nav 操作を覆わない。
- **手書きの合図。** Hero 見出しの脇（モバイルでは CTA の下）に、少し回転した「つまんでみて」 / 英語は `Pinch one.`。Klee One。本文サイズで 4.5:1。自動では動かない。

Hero の見出しは現行のまま（「小さなアプリを、丁寧に。」）。初回の文字送りも現行のまま。スクロール連動は持たない。

書体の追加は Klee One 400 だけ。`next/font/google` の latin subset では日本語が落ちるため、Fontworks の Regular を必要文字だけの woff2 に落として `next/font/local` で自己ホストする（`preload: false`）。`--font-hand`。用途は手書き合図と鉛筆メモに限る。本文・ナビ・CTA・ワードマークには使わない。Bricolage は復活させない。

### 5. 個別ページの標本

各 `/apps/<slug>/` の Hero 右上に、そのアプリのビニールを 1 枚置く。少し傾ける。すでにそのページにいるのでリンクにしない。`aria-hidden`（飾り。Swift / Tokyo と同じ）。`.app-shell` 内でつまめて、離した位置に残る。viewport 固定にしない。

法務ページ、サイト `/privacy/` `/terms/`、トップ以外には置かない。詳細ページ全体をポスター型に組み直すのは対象外。

### 6. OGP

`public/ogp.png` をクリーム紙＋電圧ブルー＋ビニール数枚の机に作り直す。`tools/generate-ogp.py` を更新し、`npm run generate:ogp` で生成する。OS フォントと外部画像には依存しない（現行どおり Pillow 同梱フォントとリポジトリ内アイコン）。ガラスパネルと紫グラデは捨てる。

`tools/` に触れるため、この変更は高リスク。独立した OpenAI / Anthropic 両系統の読み取り専用レビューを取る。

## 持たないもの

検索・フィルタ・モーダル、Liquid Glass、新規ダイカットイラスト、紙のノイズ / 染み / コーヒー輪、一覧のカード化、Hero への追加の自動演出、スクロール連動、シール位置の localStorage 永続化、viewport に張り付く HUD、ドラッグ用ライブラリ、詳細ページの全面ポスター化、DNS / Vercel / Cloudflare の設定変更。

## 検討した代替案

- **机を主役にして一覧を後ろへ下げる。** 遊びは最大だが、探しやすさと今のポスター骨格を捨てる。不採用。
- **足元の山は残して反応と飾りだけ増やす。** 最初の画面が今と同じ静けさのまま。不採用。
- **配置を毎回ランダムにする。** 机の跡というよりガチャ。E2E が脆い。不採用。
- **メモを英語 UI 用に二語用意する。** アプリ本文は日本語固定なので、tagline と同じく `stickerNote` も日本語だけにする。

## 影響

- 変更: `src/components/Stickers.tsx`（初期配置を紙全面の slot へ）、`src/styles/standard.css`、`src/styles/tokens.css`、`src/app/layout.tsx`（Klee One）、`src/app/page.tsx` / Hero / AppsSection（テープ・スタンプ・手書き）、`src/lib/site-data.ts`、`src/data/schema.ts` / `registry.ts`、`src/app/apps/[slug]/page.tsx`、`src/styles/app-page.css`、`tests/e2e/site.spec.ts`、`tests/registry.test.ts`、`docs/design/top.md`、`docs/design/app-page.md`、`docs/design/ogp.md`、`docs/TODO.md`、`specs/product.md`、`tools/generate-ogp.py`、`public/ogp.png`。
- 追加: 薄い標本コンポーネント（個別ページ用）。必要なら `Sticker` の共有を `Stickers.tsx` から分ける。専用の大きな Context は増やさない。
- 削除しない: 索引の一覧、相互ハイライト、てこの傾き、奥付、テーマと言語。
- テスト: 初期配置がフッター山だけではないこと（Hero 付近にアプリシールがある）。CTA と Nav が初期配置でクリックできる。横スクロールなし。メモがホバーと掴みで現れ、飾りには出ない。リセットで机の配置へ戻る。個別ページの標本がリンクではなくドラッグできる。axe `color-contrast` は実際の配色。OGP のピクセル一致。

## 受け入れ条件

- [ ] desktop の初期表示で、アプリシールが Hero 付近と一覧見出しに乗っている。全部がフッター山だけ、ではない
- [ ] 640px で見出しと CTA が隠れず押せる。横スクロールがない
- [ ] アプリシールの形が slug ごとに違い、alpha / beta に `α` / `β` がある。シール上にアプリ名がない
- [ ] ホバーまたは掴みで `stickerNote` が出る。飾りシールには出ない。離すと消える
- [ ] 掴み中に剥がれ（拡大）がある。`prefers-reduced-motion` では拡大しない
- [ ] マスキングテープ・TOKYO '26・手書き合図がある。粒子や染みはない
- [ ] 一覧 ↔ シールの相互ハイライト、タップ / キーボード遷移、紙座標ドラッグ、リセット、リサイズ中断が現行契約のまま動く
- [ ] 個別ページにそのアプリの標本ビニールが 1 枚あり、リンクではなくページ内で動かせる。法務ページには無い
- [ ] OGP がクリーム紙の机で、`npm run check:ogp` が通る
- [ ] `npm run verify` が通る。高リスクのため OpenAI / Anthropic 両系統の独立レビューを取る

## 検証

`npm run verify`、ローカル静的配信での light / dark / 日本語 / 英語、desktop と 640px。Hero からシールをつまみ、一覧と相互ハイライトし、個別ページの標本を動かす。ライブ本番はマージ後の別証拠。
