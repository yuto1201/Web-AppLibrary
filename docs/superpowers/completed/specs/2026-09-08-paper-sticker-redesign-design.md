# トップページ再設計 — 紙とステッカー

ステータス: 実装済み
最終更新日: 2026-09-08

## 背景

トップページは Liquid Glass テーマのまま運用してきた。暗い多重グラデーション背景、SVG 歪みフィルタ付きの半透明パネル、検索と 2 軸フィルタ、モーダルを持つ。

現状の問題は 3 つある。

1. **UI の部品が中身より重い。** 掲載アプリは 3 件だが、検索ボックス・プラットフォーム軸・カテゴリ軸・チップ・フィルタ解除・空状態を備える。3 件を絞り込む必要はない。
2. **サイト内で浮いている。** 個別アプリページ (`app-page.css`) と法務ページはすでに明色基調で、トップだけが暗い。
3. **触れる楽しさがない。** ガラスの見た目は静的で、訪問者が操作できる遊びがない。

ユーザーの要望は「もっとシンプルだが面白い」。参考は Wandor の interactive sticker footer (<https://www.inspora.design/posts/sticker-footer>) で、その芯は「ほぼ白い紙面と控えめな文字組み」+「1 箇所だけ物理的に触れる遊び」の 2 点。

## 決定

トップページを **紙 (paper) とステッカー (sticker)** の 2 要素で再構成する。

### 1. 紙の紙面へ移す

- 背景は温かみのあるオフホワイト単色。多重 radial-gradient を廃止する。
- 構造は影とぼかしではなく **1px の罫線と余白** で作る。
- `--glass-*` トークン群、`GlassFilter` コンポーネント、SVG 歪みフィルタを削除する。
- 既定テーマを `light` にし、`dark` は同じ紙面の反転（濃いインク紙）として維持する。テーマ切替は残す。

### 2. 遊びをステッカーに集約する

一覧の下に **ステッカー帯** を置く。アプリアイコンを少し傾いたステッカーとして重ねて配置し、ポインタで掴んで動かせる。

- `pointerdown` / `pointermove` / `pointerup` と `setPointerCapture` で実装する。外部ライブラリは追加しない。
- ホバーで持ち上がり、傾きが戻り、影が伸びる。
- 移動量がしきい値未満なら「タップ」と見なして個別ページへ遷移する。各ステッカーは `<Link>` なのでキーボードでは通常のリンクとして機能する。
- 移動量は帯の内側へクランプし、横スクロールを発生させない。
- `prefers-reduced-motion` では遷移アニメーションを止める。ドラッグ自体は利用者の操作なので維持する。

### 3. 削るもの

| 対象 | 理由 |
|---|---|
| 検索・プラットフォーム軸・カテゴリ軸・チップ・フィルタ解除・空状態 | 3 件に絞り込みは不要。10 件を超えたら再導入する |
| `AppModal` | 個別ページが同じ情報（機能・スクリーンショット・配布先）を持つ。一覧から直接遷移する |
| `layout` / `density` / `font` / `accent` の設定 | localStorage に保存しているが UI から切り替えられない死んだ設定 |
| `GlassFilter` と `--glass-*` トークン | 紙面では不要 |

Hero の文字送りアニメーションは維持する。

## 検討した代替案

- **暗色のままフラット化。** 既存の世界観を壊さないが、参考サイトの紙面感とは別物で、明色の個別ページとの不整合が残る。
- **白黒 + 強い 1 色。** 印刷物寄りでシャープだが硬派で、個人サイトの温かみが減る。
- **ホバー追従プレビュー（ステッカーの代わり）。** 静かで上品だが、触れる遊びにはならない。
- **ドラッグ用ライブラリの導入。** `pointerdown` 3 行で足りるものに依存を増やす理由がない。

## 影響

- 変更: `src/styles/tokens.css`、`src/styles/standard.css`、`src/styles/legal.css`、`src/components/`（Nav / Hero / AppsSection / AppCard / Sections）、`src/lib/state.tsx`、`src/app/layout.tsx`。
- 追加: `src/components/Stickers.tsx`、`src/lib/drag.ts`、`tests/drag.test.ts`。
- 削除: `src/components/AppModal.tsx`、`src/components/GlassFilter.tsx`。
- 個別アプリページ (`app-page.css`) は独自トークンで閉じているため変更しない。法務ページは `--glass-*` を参照しているので紙面トークンへ差し替える。
- E2E は検索・フィルタ・モーダル・暗色既定に強く結合しているため、該当テストを書き換える。ステッカーのドラッグとタップ遷移を新規に検証する。
- `config/acceptance.json` の AC-3 と `specs/acceptance.md`、`specs/product.md`（Liquid Glass 維持の記述）、`docs/design/top.md` を更新する。
- OGP 画像 (`public/ogp.png`) は静的生成物で、今回の意匠変更には追随しない。刷新は別 Issue にする。

## 受け入れ条件

- AC-A: トップページに検索・フィルタ・モーダルが存在せず、掲載 3 件が一覧行として表示され、行から個別ページへ遷移できる。
- AC-B: ステッカーをポインタで掴んで移動でき、移動後も横スクロールが発生しない。移動せずに離した場合は個別ページへ遷移する。
- AC-C: 既定テーマが light で、light / dark いずれでも axe の color-contrast 違反が 0 件。
- AC-D: `--glass-*` トークンと `GlassFilter` がリポジトリから消えている。
- AC-E: `npm run verify` が通り、ローカル配信でトップ・個別・法務ページの表示を確認した証跡がある。
