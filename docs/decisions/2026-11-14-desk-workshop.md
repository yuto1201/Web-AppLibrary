# サイトの方向を「机の上の工作室」にし、色をアプリごとの意味にする

ステータス: 採択
最終更新日: 2026-11-14
関連: [設計: 机の上の工作室](../superpowers/specs/2026-11-14-desk-workshop-direction-design.md)、Issue #131、Issue #132、[トップページのデザイン](../design/top.md)

---

## 背景

トップ（空色のポスター）とアプリのページ（アプリごとの専用ページ）が別の世界になっていた。一覧のカードは色を順番に塗っていて、色にアプリの意味がなく、SimplePomo と花島がどちらも緑になっていた。各アプリの色は `src/lib/app-tone.ts` にあるのに使っていなかった。詳細は設計の 1 章にある。

## 決定

設計の 8 章に従い、色を次のように置く。

- 各アプリの色を registry の `accent` に 1 つ持たせる（試作の 6 色）。
- 一覧のカードは形・枠・下半分を全アプリ共通にし、上の窓だけアプリの色で塗る。窓には文字を置かない。実画面が無いアプリはアイコンを置く。
- アプリのシールの縁に、アプリの色の細い輪（2.5px）を付ける。
- 文字のシール（Swift / Tokyo / 一人制作）は紙とインクの色にし、アプリの色を使わない。
- アプリの色は窓と輪だけに使い、文字色にしない。
- 順番塗りとパステルのカードはやめる。

## 検討した代替案

- **順番塗りのパステルを残す。** アプリと色が結びつかず、重複も出るため採らない。
- **カードの全面をアプリの色にする。** 文字との対比を各色で確かめる必要が出て、アプリごとに見え方が揺れるため採らない。窓だけにして文字は共通の紙に置く。
- **文字のシールにも色を付ける。** アプリの色と紛れ、アプリのシールとの区別が付かなくなるため採らない。

## 影響

- `src/data/registry.ts` の `accent` が色の唯一の置き場所になる。
- `VinylSticker` に任意の `color` を足し、`--app-color` として縁の輪に使う。Stickers と個別ページの標本シールが渡す。
- ホームの文字シールの黄・ミント・ラベンダーは `--paper-raised` と黒インクになる。dark の `.poster` 内でも `--paper-raised` は明るいため、文字と枠は固定の黒を使い、色のコントラストを保つ。
- 全体の方向のうち、机の地の共通化や降る物などは後続の PR で扱う。
