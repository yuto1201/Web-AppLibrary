# トップページを紙とステッカーへ再設計する

ステータス: 採択
決定日: 2026-09-08

## 背景

トップページは 2026-08-31 の Next.js 移行時に Liquid Glass テーマをそのまま移植した。暗い多重グラデーション背景、SVG 歪みフィルタ付きの半透明パネル、検索と 2 軸フィルタ、モーダルを持っていた。

3 つの不整合があった。

1. **UI の部品が中身より重い。** 掲載アプリは 3 件だが、検索ボックス・プラットフォーム軸・カテゴリ軸・チップ・フィルタ解除・空状態を備えていた。3 件に絞り込みは要らない。
2. **サイト内で浮いていた。** 個別アプリページ (`app-page.css`) と法務ページはすでに明色基調で、トップだけが暗かった。
3. **触れる楽しさがなかった。** ガラスの見た目は静的で、訪問者が操作できる箇所がなかった。

所有者の要望は「もっとシンプルだが面白い」。参考として Wandor の interactive sticker footer (<https://www.inspora.design/posts/sticker-footer>) が提示された。その芯は「ほぼ白い紙面と控えめな文字組み」と「1 箇所だけ物理的に触れる遊び」の 2 点。

## 決定

トップページを **紙 (paper) とステッカー (sticker)** で再構成する。

1. **紙の紙面へ移す。** 背景は温かみのあるオフホワイト単色。構造は影とぼかしではなく 1px の罫線と余白で作る。`--glass-*` トークン群と `GlassFilter` の SVG 歪みフィルタを削除する。既定テーマを `light` にし、`dark` は同じ紙面の反転として維持する。
2. **遊びをステッカー帯へ集約する。** アプリアイコンを傾いたステッカーとして重ね、ポインタで掴んで動かせるようにする。外部ライブラリは追加せず、`pointerdown` / `pointermove` / `pointerup` と `setPointerCapture` で実装する。計算は純粋関数に分けて単体テストを置く。
3. **過剰な操作系を削る。** 検索・2 軸フィルタ・チップ・空状態・`AppModal`、および UI から切り替えられなかった `layout` / `density` / `font` / `accent` の設定を削除する。掲載アプリが 10 件を超えたら一覧の絞り込みを再検討する。
4. **自動で動くのは初回訪問の Hero だけにする。** スクロール連動の reveal（`useReveal` と `.reveal`）を削除する。演出を 1 箇所へ集めるほうが、各セクションが順番にフェードインするより落ち着く。
5. **書体に固有性を持たせる。** 見出し・アプリ名・ワードマークへ Bricolage Grotesque を当てる。本文は Inter、日付と件数は JetBrains Mono のまま。

## 検討した代替案

- **暗色のままフラット化。** 既存の世界観を壊さないが、参考の紙面感とは別物で、明色の個別ページとの不整合が残る。
- **白黒 + 強い 1 色。** 印刷物寄りでシャープだが硬派で、個人サイトの温かみが減る。
- **ホバー追従プレビュー（ステッカーの代わり）。** 静かで上品だが、触れる遊びにはならない。
- **ドラッグ用ライブラリの導入。** `pointerdown` 3 個で足りるものに依存を増やす理由がない。

## 影響

- 実装が 1400 行以上減った。`standard.css` は 1369 行から 500 行前後へ、`AppModal` / `GlassFilter` / `AppCard` / `use-reveal` は削除。
- **コントラスト検証の証拠が強くなった。** 半透明パネルをやめて背景が単色になったため、E2E は色を上書きせず**実際の配色**で axe の `color-contrast` を判定する。以前はガラスの下の色を解決できず、テスト側で色を差し替えて判定していた。
- E2E は検索・フィルタ・モーダル・暗色既定に強く結合していたため書き換えた。ステッカーのドラッグ・クランプ・タップ遷移を新規に検証する。
- 個別アプリページ (`app-page.css`) は独自トークンで閉じているため変更していない。背景に `radial-gradient` を使うため、axe 判定時だけテスト側で単色へ倒す。
- `--accent` は `--paper` 上で 4.5:1 以上を満たす値に限る。アプリ registry の `accent` は明色紙面向けの値なので、dark では `--ink` へ戻す。
- OGP 画像 (`public/ogp.png`) は旧意匠のまま。刷新は別 Issue とする。
